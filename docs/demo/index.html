What the recording shows

This session uses the official DeepSeek API. The model reads demo order inputs, calls the native TODO tool, and saves its own answer.

The history card shows that session's task progress and latest committed reply. During generation, the last saved reply stays visible.

The video preserves the original bytes and elapsed time. It contains no generated UI, scripted model replies, or seeded TODO events.
