从源码安装

为 DSH Profile
添加历史卡片。

已验证版本为 DeepSeek Harness 0.2.2-rc.1，上游 commit 为 fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159。

DSH API 尚未稳定。调整支持版本前，先验证兼容性。插件要求 Node.js 24.9.0 或更高版本。

完整安装说明DeepSeek Harness 上游
  1. 克隆仓库并生成安装包。
    git clone https://github.com/liush2yuxjtu/dsh-sidebar-history.git
cd dsh-sidebar-history
npm pack

    命令会生成本地 tarball 安装包。

  2. 把 tarball 安装到 DSH Web Profile。

    使用该 Profile 支持的插件管理器。若使用 CLI，先运行 dsh plugin add --help，按当前 DSH 版本提供的说明安装。

  3. 打开该 Profile 的历史侧栏。

    历史卡片会显示各会话的 TODO 和最新一条已保存回复。点击底部 工作区与归档 可恢复原生工作区导航。

安装前了解这些行为。

仓库保存完整的功能说明、兼容范围和验证要求。

插件会修改 DeepSeek Harness 源码吗？

不会。它是外部插件。bundle patch 注册会话投影，client export 通过官方 DSH 接口提供浏览器模块。

侧栏会启动每个历史会话的 Agent 吗？

不会。卡片按需读取有长度限制的投影。客户端复用会话列表，只渲染可见区域及少量预加载行。已归档会话默认隐藏。

任务进度和回复摘要从哪里来？

任务来自 todo/write。新一轮 turn/start 会清空上一轮任务。回复摘要来自已提交的 assistant/message 文本。加载、失败、空会话和非文本消息都有明确状态。

如何验证插件？

仓库包含单元、打包、受控浏览器、真实 API 和媒体检查。pre-commit 验证器检查暂存内容，并要求一次新的真实 API E2E。查看验证命令与验证报告。
