01 · 任务

真实 TODO 状态

显示完成数与总数，最多展示三项任务，进行中和待处理任务优先。状态来自原生 todo/write。新一轮清空上一轮任务；本轮无任务不代表此前工作已完成。

02 · 回复

最新正式回复预览

两行展示已保存回复，并区分此前回复与本轮进度。空消息或纯工具消息保留有用文本。生成中、停止或失败描述当前轮次；中断输出、推理和工具结果不会进入摘要。

03 · 历史

搜索和键盘导航

搜索结合缓存标题、回复与 DSH 官方内容搜索。远程失败时保留本地结果，标明搜索不完整并提供重试；达到结果上限时显示提示。仅远程匹配与滚动位置在导航后保留。支持方向键、Home、End 和 Enter。

04 · 集成

保留 DSH 原生外壳

使用官方 projection 和 slot 接口，保留原生外壳、折叠及手机抽屉。底部的工作区与归档打开原生操作，历史卡片恢复搜索、滚动和聚焦会话。

侧栏跟随 DSH 的语言设置，支持英文、简体中文、繁体中文、日语和西班牙语。繁体中文宿主语言包覆盖 17 个 namespace、1829 个 key；其他 namespace 可能回退为简体中文。

从源码安装

为 DSH Profile
添加历史卡片。

此 checkout 构建 DSH Sidebar History 0.2.3。已验证的 DSH 目标为 DeepSeek Harness 0.2.2-rc.1，上游 commit 为 fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159。

DSH API 尚未稳定。调整支持版本前，先验证兼容性。插件要求 Node.js 24.9.0 或更高版本。

完整安装说明DeepSeek Harness 上游
  1. 克隆仓库并生成安装包。
    git clone https://github.com/liush2yuxjtu/dsh-sidebar-history.git
cd dsh-sidebar-history
npm pack

    命令会生成含预构建浏览器模块的本地 tarball。维护者修改客户端源码后运行 npm run build:client；构建会拒绝过期 bundle 或许可证声明。

  2. 把 tarball 安装到 DSH Web Profile。
    dsh plugin --profile web add "$PWD/dsh-sidebar-history-0.2.3.tgz"

    在刚克隆的仓库目录运行此命令。若使用其他 Web Profile，替换 web。Profile 选项放在 add 前。也可使用该 Profile 的插件管理器。

  3. 打开该 Profile 的历史侧栏。

    历史卡片会显示各会话的 TODO 和最新一条已保存回复。点击底部 工作区与归档 可恢复原生工作区导航。

安装前了解这些行为。

仓库保存完整的功能说明、兼容范围和验证要求。

插件会修改 DeepSeek Harness 源码吗？

不会。它是外部插件。bundle patch 注册会话投影，client export 通过官方 DSH 接口提供浏览器模块。

侧栏会启动每个历史会话的 Agent 吗？

不会。卡片按需读取有长度限制的投影，并显示加载或失败状态。v2 从持久化日志回放旧检查点，不激活历史 Agent。客户端复用会话列表，只渲染可见区域及少量预加载行。已归档会话默认隐藏。

任务进度和回复摘要从哪里来？

任务来自 todo/write。新一轮 turn/start 会清空上一轮任务。回复摘要来自已提交的 assistant/message 文本。加载、失败、空会话和非文本消息都有明确状态。

Markdown 预览如何显示？

只读预览使用与 DSH 相同的 GFM 语法，显示粗体、斜体、删除线和代码。列表与表格压缩为文本，链接显示标签，图片显示替代文本。预览不会跳转、加载远程图片或解释原始 HTML。无障碍描述包含任务数量、各项状态、回复及轮次上下文。

如何验证插件？

仓库包含单元、打包、受控浏览器、真实 API 和媒体检查。pre-commit 验证器检查暂存内容，并要求一次新的真实 API E2E。查看验证命令与验证报告。
